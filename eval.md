## **📊 Evaluation Criteria for Task Manager App**

Each submission will be evaluated based on the following key areas:  

### **1️⃣ Functionality (24 points)**  
- ✅ **Basic CRUD Operations (8 points)**: The app can create, read, update, and delete tasks.  
- ✅ **Task Completion (4 points)**: Users can mark tasks as completed or pending.  
- ✅ **Filtering (4 points)**: Users can filter tasks by status (All, Completed, Pending).  
- ✅ **Sorting (4 points)**: Users can sort tasks by due date.  
- ✅ **API Integration (4 points)**: The app successfully fetches and updates tasks using `json-server` API.  

---

### **2️⃣ Code Quality & Best Practices (8 points)**  
- ✅ **Component Structure & Reusability (2 points)**: The app follows a modular component structure with reusable components.  
- ✅ **Code Readability & Maintainability (2 points)**: Code is clean, well-structured, and easy to understand.  
- ✅ **State Management (2 points)**: Effective use of React hooks (`useState`, `useEffect`, etc.) for managing state.  
- ✅ **Folder Organization (2 points)**: Uses a well-organized project structure following React best practices.  

---

### **3️⃣ UI & Navigation (14 points)**  
- ✅ **User-Friendly Interface (2 points)**: The UI is clean, responsive.  
- ✅ **React Router Implementation (4 points)**: Dynamic routing is implemented for navigation between pages (`/`, `/task/:id`, `/add-task`, `/edit-task/:id`).  
- ✅ **Form Validation (4 points)**: All required fields in the form are validated as per the given criteria (title, due date, etc.).  
- ✅ **Error Handling (4 points)**: Proper handling of API errors and user input errors.
